# Art Mob Tool Catalog

**Status: Proposed capability concepts — not verified live software**

This catalog captures specialized tool concepts associated with each Mob for website planning and future registry work. The tool names and descriptions are design inputs. They do not establish that software exists, is integrated, has been tested, or is available to clients.

Before any tool is presented as live or callable, verify its implementation, owner, inputs, outputs, permissions, dependencies, quality checks, limitations, and deployment status. Avoid implying monitoring, prediction, regulatory compliance, security guarantees, or automated actions unless specifically evidenced.

## Website presentation guidance

The Mob detail view may include a **Tools & methods** tab or section with each entry shown as a proposed capability concept until verified. Use these fields in the future registry:

- Name and Mob
- Problem addressed
- Intended function
- Inputs and data sensitivity
- Outputs
- Human review required
- Implementation owner
- Dependencies and permissions
- Current status: concept, prototype, verified live, retired
- Evidence link and last verification date

Do not describe illustrative industry applications as customer experience, deployments, case studies, or proven results.
